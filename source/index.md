# Introduction {-}

`flandersqmd-leaflet` is a quarto template for leaflets with the corporate identity of the Flemish government.
It is based on the `flanderqmd-book` template by [INBO](https://github.com/inbo/flandersqmd-book).
Visit https://inbo.github.io/flandersqmd-leaflet/ to view the rendered version of the example.

This is a very minimal example.
More examples of different content and formatting options are available in the GitHub repo [flandersqmd-book](https://github.com/inbo/flandersqmd-book).
